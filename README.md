# 미국 기관투자자 유형 분석 - SEC Form 13F

'대규모언어모델(LLM)를 활용한 빅데이터분석' 수업 프로젝트

미국의 큰 기관투자자들이 분기마다 공개하는 보유 주식 명세를 가지고, 이들을 투자 성향에 따라 몇 가지 유형으로 나누고 유형마다 사고파는 방식이 어떻게 다른지 본다.

## 현재 진행 상태

| 단계 | 상태 | 산출물 |
|---|---|---|
| 1차 - 기획 | 진행 중 (10/05 제출) | [`01_proposal/01_proposal.md`](01_proposal/01_proposal.md) |

| 4차 - 최종 | 예정 (12월 말) | `04_final/` |

## 핵심 분석 질문

1. 기관투자자를 투자 성향(보유 종목 수, 쏠림 정도, 사고파는 빈도, 옵션 비중)으로 나누면 몇 가지 유형이 나오는가?
2. 유형마다 사고파는 방식이 실제로 다른가?
3. 여러 기관이 같은 종목을 동시에 사들이는 쏠림이 시기에 따라 달라지는가?

## 데이터

**SEC Form 13F Data Sets** - <https://www.sec.gov/data-research/sec-markets-data/form-13f-data-sets>

- 누구나 무료로 받을 수 있고, 계정이나 API 키가 필요 없다
- 받을 수 있는 분기: 53개 (2013Q2 ~ 2026Q2, 2026-09-27 확인)
- 분석 대상: 2019Q1 ~ 2026Q2 (30개 분기)
- 크기: 한 분기가 약 289만 행

## 다시 실행하는 법

```sh
uv run src/probe_data.py --only sec --list   # 받을 수 있는 분기 목록 (몇 초)
uv run src/probe_data.py                      # 시험 삼아 받아보고 품질 확인
```

결과는 `probe_out/` 에 생긴다.

- `report.md` - 데이터 품질 확인 결과
- `samples/*.csv` - 각 표의 앞 200줄

## 확인한 데이터 품질 문제

자세한 수치는 [기획서 8절](01_proposal/01_proposal.md)에 있다.

| 문제 | 직접 확인한 값 |
|---|---|
| `VALUE` 금액 단위가 바뀜 (2023-01-03, 천 달러 → 달러) | 주당 단가 중앙값 2022Q3 `0.0542` vs 2023Q4 `47.56` - 약 880배 |
| 공시가 늦게 올라옴 (아직 공개 안 된 정보를 미리 쓰게 됨) | 보유 기준일에서 공시일까지 중앙값 **44일**, 45일 초과 9.0% |
| 고쳐 다시 낸 보고서 | 전체의 3.4% (`RESTATEMENT` / `NEW HOLDINGS`) |
| 뒤늦게 공개된 비밀 보유 | 전체의 1.1% |
| 지저분한 문자열 | `NAMEOFISSUER` 공백-쓰레기값, `CUSIP` 대소문자 섞임과 빈 코드값 |

## 한계

- 13F는 분기말 한 시점의 사진이라, 분기 중에 사고판 건 보이지 않는다
- 사들인 종목만 보고하고, 공매도는 들어있지 않다
- 운용 규모 1억 달러 이상인 큰 기관만 보고 의무가 있다
- 미국 시장만 다루므로, 결론을 다른 시장에 그대로 적용하지 않는다
